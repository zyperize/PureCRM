# Changelog

All notable PureCRM changes are documented here.

## [1.2.1] - 2026-07-28

### Added

- Permanent Import Data navigation and Import & Export access in Settings
- Clear local-database and optional Team Database choices

### Fixed

- First-run setup now continues directly to Excel/CSV import
- Sidebar hover labels no longer cover labels that are already visible
- Selected navigation and controls maintain readable contrast across themes and
  accent colors
- Collapsed navigation retains accessible names and correctly positioned
  tooltips

## [1.2.0] - 2026-07-28

### Added

- PureCRM desktop identity and flat application icon
- Live appearance and accent previews during first-run setup
- Universal macOS DMG and Windows x64 installer

### Fixed

- Light-mode dashboard surfaces now use readable theme-aware colors
- Existing local Clean CRM data and backup files remain compatible

## [1.1.0] - 2026-07-28

### Added

- Local-first IndexedDB workspace with no required account or database
- Excel and CSV import with automatic common-header matching
- Local backup, restore, reset, and optional Supabase Team sync
- Tauri desktop packaging for Windows and macOS
