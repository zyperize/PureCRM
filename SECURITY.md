# Security policy

## Supported version

Security fixes are applied to the latest published PureCRM release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
**Security → Report a vulnerability** flow for this repository.

Include:

- the affected version and platform,
- clear reproduction steps,
- the expected and observed behavior, and
- the potential impact.

Never attach real leads, customer records, backups, credentials, tokens, or
other private business data. Use fictional test data only.

## Local data

PureCRM stores local workspaces in the app/browser data directory. Users are
responsible for protecting their operating-system account and exported backup
files. Optional third-party integrations are governed by those providers'
security and privacy practices.
